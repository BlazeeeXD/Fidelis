# Fidelis dashboard hotfix — 18 November 2026

## Fixed

The Control Room's **Send sample PR event** button was issuing `GET /demo-api/events?action=opened`. The Gateway correctly exposes this state-changing endpoint as `POST`, so the browser received `405 Method Not Allowed`.

The dashboard now passes `{method: 'POST'}` when sending the sample event. The shared JSON request helper accepts optional fetch options, preserving its existing GET behavior for health probes. The backend contract was intentionally left unchanged.

## Regression coverage

- Dashboard source is checked to ensure the sample event uses POST.
- The API is checked to reject GET for this state-changing endpoint.
- Existing gateway tests continue to cover successful signed event delivery and replay behavior.

## Apply

Replace the contents of your existing project folder with this package, or copy `services/gateway/app/static/index.html` and `services/gateway/tests/test_gateway.py` over the corresponding files in your current checkout. Rebuild/recreate the Gateway container so Docker picks up the changed static dashboard:

```powershell
docker compose up -d --build gateway
```

Then hard-refresh the Control Room page (`Ctrl + Shift + R`) and click **Send sample PR event**. Keep your existing `.env` values.
